# EduRAG 前端需求文档

## 1. 项目概述

**项目名称**: EduRAG 教育问答前端
**项目类型**: 单页应用 (SPA)
**核心功能**: 为 EduRAG 后端系统提供友好的交互界面，支持流式答案输出、对话历史管理、多学科检索。
**目标用户**: 学生、教师、教育从业者

---

## 2. 技术选型

| 类别 | 选择 | 说明 |
|------|------|------|
| 框架 | Vue 3 (Composition API) | 轻量级、易上手、生态成熟 |
| 构建工具 | Vite | 快速启动、热更新 |
| 样式 | 原生 CSS + CSS Variables | 简洁、无依赖 |
| HTTP 客户端 | Fetch API | 原生支持 SSE |
| 状态管理 | Vue 3 `reactive` | 够用、不引入额外复杂度 |

> **说明**: 若倾向其他框架（React/Angular）或引入 UI 库（ElementUI/Ant Design），可替换，技术选型不是强约束。

---

## 3. UI 设计规范

### 3.1 主题切换

支持**浅色模式**（默认）和**深色模式**，一键切换。

| 模式 | 背景色 | 文字色 | 边框色 |
|------|--------|--------|--------|
| 浅色 | `#ffffff` | `#333333` | `#e0e0e0` |
| 深色 | `#1a1a1a` | `#e0e0e0` | `#333333` |

主题偏好存储于 `localStorage`，页面刷新后保持。

### 3.2 页面布局

```
┌─────────────────────────────────────────────┐
│  Header: Logo + 主题切换按钮                  │
├─────────────┬───────────────────────────────┤
│  Sidebar    │  Main Content                 │
│  - 学科选择  │  - 对话区域 (消息列表)           │
│  - 会话列表  │  - 输入框 + 发送按钮            │
│  - 新建会话  │                               │
└─────────────┴───────────────────────────────┘
```

- **左侧边栏** (宽度 240px): 学科选择器 + 会话管理
- **右侧主区域**: 对话消息展示 + 输入操作
- **Header**: 高度 56px，包含标题和主题切换

### 3.3 组件设计

| 组件 | 功能说明 |
|------|----------|
| `Header` | 显示标题 "EduRAG 问答系统"，右侧放置主题切换按钮（太阳/月亮图标） |
| `SubjectSelector` | 下拉选择框，支持学科: `ai`, `java`, `test`, `ops`, `bigdata`，默认"全部" |
| `SessionList` | 显示所有会话记录，每条显示首问摘要 + 时间，点击切换当前会话 |
| `NewSessionButton` | 点击创建新会话，清空对话区域 |
| `MessageList` | 展示问答消息，用户消息右对齐（灰色背景），AI 回答左对齐（白色/深色背景） |
| `SourceDisplay` | 位于 AI 回答下方，展示检索来源文档块（可折叠，点击展开查看原文） |
| `InputArea` | 文本输入框 + 发送按钮，支持 Enter 提交 |

## 4. 功能模块详细说明

### 4.1 学科分类选择

- 提供下拉选择器，选项: `全部`、`AI`、`Java`、`Test`、`Ops`、`BigData`
- 选择后，后续查询自动带上 `source_filter` 参数
- 默认值为"全部"（不过滤）

### 4.2 会话管理

- **新建会话**: 点击侧边栏按钮，清空对话历史，生成新 `session_id`
- **切换会话**: 点击侧边栏的历史会话，恢复该会话的对话记录
- **会话持久化**: 仅在当前 Tab 有效（可扩展为 localStorage 持久化）
- **会话列表**: 显示最近 N 条会话，每条显示首条问题（截断20字）+ 时间

### 4.3 流式答案展示（打字机效果）

- AI 回答采用 **SSE (Server-Sent Events)** 流式接收
- 每收到一个 token，立即追加到回答文本并渲染
- 打字过程中显示加载动画（三个点跳动）
- 回答完成后，隐藏加载动画

### 4.4 多轮对话历史

- 用户发送消息后，用户问题和 AI 回答成对显示
- 回答区域实时显示流式内容
- 历史消息不因新查询而消失（除非新建会话）

### 4.5 显示检索来源/文档块

- AI 回答完成后，在回答下方展示"参考文档"区域
- 显示文档块内容摘要（最多显示3条）
- 每条显示：来源学科、文档摘要（截断100字）、展开按钮
- 点击展开可查看完整文档块内容

## 5. API 接口说明

### 5.1 查询接口

**接口**: `POST /query`

**请求体**:
```json
{
  "query": "什么是人工智能？",
  "source_filter": "ai",
  "session_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | 是 | 用户问题 |
| `source_filter` | string | 否 | 学科过滤，如 "ai"，不传则不过滤 |
| `session_id` | string | 否 | 会话 ID，不传则自动生成 |

**响应**: SSE 流式格式

```
data: {"token": "这", "is_complete": false, "session_id": "xxx"}\n\n
data: {"token": "是", "is_complete": false, "session_id": "xxx"}\n\n
data: {"token": "一", "is_complete": false, "session_id": "xxx"}\n\n
data: {"error": "...", "is_complete": true}\n\n
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `token` | string | 当前生成的文本片段 |
| `is_complete` | boolean | 是否为最后一个片段 |
| `session_id` | string | 服务端返回的会话 ID |
| `error` | string | 错误信息（仅出错时存在） |

## 6. 前端状态管理

```javascript
// 核心状态
{
  theme: 'light' | 'dark',
  currentSessionId: string | null,
  sessions: [{ sessionId, firstQuestion, timestamp }],
  messages: [{ role: 'user' | 'assistant', content, sources?, timestamp }],
  currentSubject: string | null,  // null 表示全部
  isStreaming: boolean,
  inputValue: string
}
```

## 7. 验收标准

| 功能 | 验收条件 |
|------|----------|
| 主题切换 | 点击按钮可切换黑白模式，刷新后保持 |
| 学科选择 | 选择后发送的请求携带正确 source_filter |
| 新建会话 | 清空消息列表，生成新 session_id |
| 切换会话 | 点击历史会话加载对应对话记录 |
| 流式输出 | 答案逐字显示，有打字机效果 |
| 对话历史 | 多轮对话依次展示，不被覆盖 |
| 检索来源 | 回答完成后显示参考文档，可折叠展开 |

## 8. 附加说明

1. **兼容性**: 支持 Chrome/Firefox/Edge 现代浏览器
2. **响应式**: 最小宽度 1024px，移动端可简化布局
3. **错误处理**: 网络错误时显示友好提示，不丢失用户输入
4. **可扩展**: 若后续需要登录、用户管理，可在此架构上扩展
